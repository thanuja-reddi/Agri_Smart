# 🌿 Leaf Disease Detection & Crop Recommendation System

## 📌 Project Overview

This project is a **machine learning-based system** designed to help farmers detect plant leaf diseases and make better agricultural decisions.

It combines:

* 🌱 Leaf disease detection using image classification
* 🎥 Educational video recommendations
* 🌾 Crop prediction based on environmental factors

The system provides **quick, accessible, and practical insights** for farmers.

---

## 🚀 Features

### 🌿 Leaf Disease Detection

* Upload plant leaf images
* Detect diseases using a trained machine learning model
* Provides instant prediction results

### 🎥 Educational Support

* Suggests videos related to:
  * Disease prevention
  * Treatment methods
* Helps farmers take corrective actions

### 🌾 Crop Recommendation

* Predicts suitable crops based on:

  * Season
  * Water availability
* Assists in better agricultural planning

### 💻 User-Friendly Interface

* Simple and easy-to-use design
* Farmers can upload images and get results quickly

---

## 🛠️ Technologies Used

* Python 🐍
* Machine Learning
* NumPy
* UI framework

---

## 🧠 How It Works

1. Image input is provided by the user
2. Image is preprocessed (resizing, normalization)
3. Machine learning model classifies the disease
4. System displays:

   * Disease prediction
   * Suggested videos
   * Crop recommendations

---

* Successfully detects plant diseases from leaf images
* Provides useful learning resources for farmers
* Suggests crops based on environmental conditions
